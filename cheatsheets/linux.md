# Linux commands cheatsheet

| Goal | Command |
|------|---------|
| Find files by name | `find / -name "file.txt" 2>/dev/null` |
| Search inside files | `grep -ri "keyword" /path` |
| Check listening ports | `ss -tulnp` |
| Current user and groups | `id` |
| Sudo permissions | `sudo -l` |
| File permissions | `ls -la` |

_Add to this as you learn._
